# Flujo profesional de desarrollo

## Rama de trabajo
Se utiliza una rama feature separada de main.

## Commits
Los cambios se registran en commits descriptivos.

## Pull Request
Se solicita integrar el trabajo a main mediante
un Pull Request en GitHub.

## Revision cruzada
Otro colaborador revisa los archivos modificados
y registra su aprobacion en GitHub.

## Merge
Despues de la aprobacion se fusiona el PR con main.

## Verificacion
Se comprueba que los archivos de practica-2
esten disponibles en la rama principal.
